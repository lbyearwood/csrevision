# Planning

This directory contains the project's implementation plans, operating procedures, technical references, curriculum content and QA records.

## Directory guide

- `Process/` - Codex start/development/end procedures, the current handover and the live project task list.
- `Setup/` - local development, Supabase, deployment, release and troubleshooting runbooks.
- `Architecture/` - data, security, Edge Function, scope, marking and seed-content design references.
- `Curriculum/` - curriculum mappings, specifications and question-type planning.
- `Testing/` - the QA process, sequential test checklist and outstanding blocked tests.
- `Design/` - shared visual references and UI baselines.
- `Prototypes/` - runnable mock designs, interaction experiments and disposable mini-sites.
- `Work Packages/` - feature-specific plans, notes and supporting assets.

## Start here

1. Read `Process/CODEX_START_PROCESS.md`.
2. Read `Process/HANDOVER.md` and `Process/PROJECT_TASKS.md`.
3. Open the relevant category for the work being performed.
4. Use `Process/CODEX_DEVELOPMENT_PROCESS.md` for the required QA gate.
