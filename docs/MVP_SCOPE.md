# MVP Scope

Included in MVP v1:

- React/Vite/Tailwind frontend.
- GitHub Pages-compatible routing.
- Supabase schema and RLS foundations.
- Teacher/student/admin role model.
- Teacher-owned classes.
- Teacher-created student accounts.
- Username and public Student ID generation rules.
- Subject -> Unit -> Topic -> Test -> Version -> Question hierarchy.
- Practice and assigned assessment flows.
- Assigned attempt consumed at start.
- Controlled reset/void for assigned attempts.
- Server-side marking Edge Function.
- Autosave.
- Suspicious activity logging.
- Watermark and print deterrents.
- Points ledger and status levels.
- Class leaderboard.

Not included in MVP v1:

- AI written-answer marking.
- Certificates.
- Bulk CSV import UI.
- Bulk CSV export UI.
- Advanced analytics.
- Parent accounts.
- Email notifications.
- Student self-registration.
- Teacher self-registration.
- Payments.
- Public marketing pages beyond login.
